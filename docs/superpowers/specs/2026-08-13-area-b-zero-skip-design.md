# B 区零干旱位置跳过设计

## 目标

B 区车辆仍按既定路线移动到全部六个位置。当当前位置的干旱程度为 `0` 时，跳过该位置的机械臂转向、语音播报和喷水动作，然后继续处理下一个位置。

## 状态流

- 状态 `0` 和状态 `1` 的车辆移动职责保持不变。
- 进入状态 `2`（左侧位置）或状态 `3`（右侧位置）时，读取 `area_B_situation[area_B_current_position]`。
- 干旱程度非零时，继续现有流程：机械臂转向、进入状态 `4` 播报、进入状态 `5` 喷水，再推进位置。
- 干旱程度为零时，不调用机械臂转向、语音播报或喷水任务，直接推进当前位置。
- 跳过偶数位置后继续处理同组的奇数位置；跳过奇数位置后进入状态 `6`，执行回正并继续下一组。
- 六个位置处理完成后，保持现有行为，进入状态 `7`。

## 实现约束

- 抽取一个仅负责“完成当前位置、增加索引并安排下一状态”的内部辅助函数，由正常喷水流程和零值跳过流程共同调用。
- 辅助函数不负责车辆移动、机械臂动作、播报或喷水，避免扩大职责。
- 修正 B 区状态 `5` 延时计算中误用 `area_A_current_position` 的问题，统一使用当前 B 区位置及其干旱程度。
- 不修改 A 区逻辑，不实现当前标记为 TODO 的车辆移动逻辑。

## 边界行为

- 单个零值：只跳过该位置的灌溉动作，下一位置正常处理。
- 连续零值：逐个推进，不能停留在当前状态，也不能启动水泵。
- 零值后接非零值：非零位置仍正常执行转向、播报和喷水。
- 最后一个位置为零：推进到位置总数后进入状态 `6`，随后进入状态 `7`。
