# A 区避障状态机设计

## 目标

补全 `A_obstacle_avoidance_state_machine` 的初始化、状态动作和定时切换逻辑。状态机支持从状态 0 或状态 1 进入，并在完成避障后退出到 `STATE_MACHINE_NO_STATE`。

## 状态路径

- 从状态 1 进入：`1 -> 3 -> 0 -> 5 -> 6 -> 7 -> STATE_MACHINE_NO_STATE`
- 从状态 0 进入：`0 -> 2 -> 1 -> 5 -> 6 -> 7 -> STATE_MACHINE_NO_STATE`

## 状态动作与时序

| 状态 | 动作 | 下一状态 | 延时 |
| --- | --- | --- | --- |
| 0 | 相对当前角度左转 `+40°` | 2 或 5 | 1200 ms |
| 1 | 相对当前角度右转 `-40°` | 3 或 5 | 1200 ms |
| 2 | 沿当前角度前进 0.7 m | 1 | 2500 ms |
| 3 | 沿当前角度前进 0.7 m | 0 | 2500 ms |
| 5 | 以 `-radar_get_axis[1]` 为位移沿 Y 轴移动到 `y = 0` | 6 | 3000 ms |
| 6 | 以 `-radar_get_angle` 为相对转角转到绝对角度 0 | 7 | 1200 ms |
| 7 | 沿 X 轴移动到 `oa_current_set_target_x` | `STATE_MACHINE_NO_STATE` | 按距离计算 |

状态 0 和状态 1 的下一状态取决于进入避障状态机时选择的路径。状态机保存本次路径方向，使状态 0/1 在第二次出现时进入状态 5。

## 状态 7 延时

进入状态 7 时计算：

```text
x_delta = oa_current_set_target_x - radar_get_axis[0]
delay_ms = abs(x_delta) / 0.3 * 1000
```

动作调用使用相同的 `x_delta` 和 `0.3 m/s` 速度。时间换算需要处理非有限坐标、极小距离和 `uint32_t` 范围，避免无效移动或整数溢出。

## 集成方式

在 `User_Init` 中以 `STATE_MACHINE_NO_STATE` 初始化该状态机，在急停流程中退出该状态机。状态回调沿用现有 `State_Change_WithDelay` 调度方式，不引入新的调度任务。

## 测试

主机测试通过替身记录动作和延时，验证两条完整路径、各状态动作与参数、固定延时、状态 6 的绝对角度回正计算，以及状态 7 的距离延时换算和最终退出行为。
