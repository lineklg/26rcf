# 车轮角度保持 PID 设计

## 目标

在现有四轮速度环中增加一个独立的角度保持 PID。角度保持只在
`enable_fix_angle == 1U` 时参与计算，将雷达角度稳定在通过独立接口预先设置的
目标值；禁用时不计算角度 PID，也不改变现有速度 PID 与前馈输出。

## 接口与状态

在 `Core/User/wheel_pid.h` 中新增：

- `extern uint8_t enable_fix_angle`：公开角度保持使能变量，非零值统一按启用处理。
- `WheelPID_SetTargetAngle(float target_angle)`：设置 `radar_target_angle`，输入单位为
  弧度，并归一化到 `[-pi, pi]`。

`Core/User/wheel_pid.c` 内部保存独立的角度 PID、目标角度和上一次观察到的使能
状态。初始化时创建角度 PID，默认参数为 `Kp = 0.2f`、`Ki = 0.0f`、
`Kd = 0.0f`，输出绝对值上限为 `0.05f`。角度 PID 与四个轮速 PID 共用现有
20 ms 调度周期。

## 控制流程

每次 `PID_Task()` 执行时，先比较当前 `enable_fix_angle` 与上一次状态。只要状态
发生变化，就调用 `PID_ResetHistory()` 清除角度 PID 的积分和上次反馈历史，然后
记录新状态。这样即使外部直接修改公开变量，下一次控制计算也会在使用新状态前
完成清理。

当角度保持启用且角度 PID 创建成功时，使用 `radar_target_angle` 与
`radar_get_angle` 计算最短有符号角误差，并将误差归一化到 `[-pi, pi]`。例如目标
为 `179` 度、反馈为 `-179` 度时，误差为 `-2` 度。角度 PID 每个任务周期只计算
一次，输出由 PID 自身限制在 `[-0.05f, 0.05f]`。

在每个车轮原有的速度 PID 与前馈之和 `result` 上叠加角度修正：A、C 轮加角度
PID 输出，B、D 轮减角度 PID 输出。负输出会自然反转上述修正方向。禁用角度
保持时修正量为零，不调用角度 PID 计算。

`WheelPID_Stop()` 保持现有停车语义；角度 PID 的历史由使能状态变化负责清除，
目标角度继续保留，供下一次启用使用。

## 边界与故障处理

- 角度目标和反馈跨越 `-pi/pi` 边界时使用最短方向，不产生接近一整圈的误差。
- 角度 PID 创建失败时跳过角度修正，四轮速度环仍按原逻辑运行。
- 不在本功能中新增最终占空比限幅；继续由现有电机驱动边界处理最终输出。
- 不修改雷达数据接收、行为层和 STM32 自动生成代码。

## 测试

扩展 `tests/wheel_pid_test.c`，使用真实 `pid.c` 与任务调度实现，测试至少覆盖：

1. 禁用时四轮输出保持原有结果，角度偏差不产生修正。
2. 启用时正角误差使 A、C 轮增加，B、D 轮减少；负角误差方向相反。
3. 大角误差下修正量限制为 `0.05f`。
4. `179` 度与 `-179` 度附近按最短角误差计算。
5. `enable_fix_angle` 在启用和禁用之间切换后，角度 PID 历史在下一次任务计算前
   被清除。
6. 原有独立轮速、直行、转向和停止测试继续通过。
