# VOFA 小端字节转浮点数设计

## 目标

在 `User/vofa.c` 和 `User/vofa.h` 中新增一个转换函数，将包含 IEEE 754 单精度浮点数位模式的四字节数组按小端顺序转换为 `float`。

## 接口

```c
float VOFA_BytesToFloatLE(const uint8_t data[4]);
```

- `data[0]` 为最低有效字节，`data[3]` 为最高有效字节。
- 输入指针只读，函数不修改输入数据。
- `data` 为 `NULL` 时返回 `0.0f`。
- 声明使用中文 Doxygen 注释，明确参数、返回值和字节序约定。

## 实现

函数将四个输入字节通过移位和按位或运算显式组装成 `uint32_t` 位模式，再用 `memcpy` 将该位模式复制到 `float`。这种实现不依赖处理器本身的字节序，不执行未对齐读取，也不违反 C 的严格别名规则。

工程当前目标平台及测试平台均要求 `float` 为 32 位 IEEE 754 单精度格式；在实现中通过编译期断言检查 `sizeof(float) == sizeof(uint32_t)`。

## 测试

新增独立的主机端断言测试，至少验证：

- `00 00 00 00` 转换为 `0.0f`。
- `00 00 80 3F` 转换为 `1.0f`。
- `00 00 20 C0` 转换为 `-2.5f`。
- `NULL` 输入返回 `0.0f`。

先编译并运行测试确认其因接口尚未实现而失败，再实现函数并重新运行测试。最后执行工程构建，确认新增接口未破坏 STM32 固件编译。
